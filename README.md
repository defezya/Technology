# Technology — Django интернет-магазин

## Запуск на Windows

1. Установите Python 3.11 или новее.
2. Распакуйте архив и откройте папку `technology_django` в VS Code.
3. Откройте терминал в папке проекта и выполните:

```powershell
py -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
py manage.py makemigrations store
py manage.py migrate
py manage.py createsuperuser
py manage.py runserver
```

4. Откройте `http://127.0.0.1:8000/`.
5. Панель администратора: `http://127.0.0.1:8000/admin/`.

## Первоначальная настройка

Войдите в `/admin/` под созданным суперпользователем. Добавьте категории, затем товары. Фото можно загружать прямо в карточке товара.

## Возможности

- каталог с поиском, фильтром по категории и сортировкой;
- регистрация, вход и выход;
- корзина в сессии пользователя;
- проверка остатков при добавлении и оформлении заказа;
- оформление заказа с подтверждением паролем;
- история заказов, удаление нового заказа с возвратом товаров на склад;
- административное управление товарами, категориями и статусами заказов.
